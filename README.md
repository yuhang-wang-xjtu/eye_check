# 20·20·20 Windows 护眼提醒

下载最新版：[GitHub Releases](https://github.com/yuhang-wang-xjtu/eye_check/releases/latest)。Windows 下载 `EyeBreak-Windows-x64-v0.2.1.zip`，退出旧程序后解压运行 `EyeBreak.exe`；设置和记录保留在原 LocalAppData 目录。Android 下载 `EyeBreak-Android-v0.2.1.apk` 覆盖安装，之后可在设置页“检查 GitHub 更新”。Windows 暂不提供应用内更新。

v0.2.1 为原型发布。Android APK 使用调试签名，覆盖更新必须保持签名一致；签名密钥不得提交仓库。Windows 发布包使用静态 MSVC 运行库构建（CMake 配置加 `-DCMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded`）。发布附件提供 SHA-256 清单。

Android Kotlin 原型已加入 [android/](android/README.md)，共享会话参考服务及部署说明见 [sync/](sync/README.md)。Android 与现有 Windows 程序的实际跨端互联仍需部署服务端并接入 Windows 客户端。

C++17 + Win32 原生窗口与系统托盘，无第三方运行框架。

## 功能

- 启动后每 20 分钟提醒，休息默认 25 秒，可在设置中调整至 1–600 秒。修改时长从下次休息生效。
- 休息完成后停止计时，点击“继续工作”或产生新的鼠标移动、鼠标点击或键盘操作才开始下一个完整 20 分钟周期。休息期间的操作不会提前结束休息。
- 休息完成时另播放一次所选提示音，并弹出“休息完成”提醒；仍需用户操作才恢复计时，等待期间不会重复播放。
- 外接输入也可恢复等待中的计时：支持常见 XInput 手柄，以及系统识别的 HID 游戏手柄、摇杆、多轴控制器、数位笔和媒体控制器。使用按钮、方向键、摇杆、扳机等控件时检测状态变化；连接设备、相同数据持续上报不恢复，摇杆中心小幅抖动会过滤。旧式 WinMM 游戏控制器轮询已移除，只有旧接口而不提供 HID/XInput 的设备不再支持。
- 首次设备状态用于建立基线，厂商私有协议的设备不保证识别，具体型号需真机测试。不会记录输入内容或阻止设备在其他软件中使用。外接设备活动与鼠标键盘一样，可恢复等待或离开状态，不能提前结束休息，也不会解除手动暂停。
- 常驻桌面的悬浮图标显示倒计时 / 暂停 / 休息回补 / 待继续状态；拖动可移动并保存位置，单击打开主窗口，右键打开操作菜单。它位于普通窗口上方、不抢焦点，可在设置中关闭。
- 手动休息统一为“立即休息”，全局热键 `Ctrl+Alt+L` 切换立即休息 / 继续工作：离开时保留当前倒计时，按离开 1 秒增加 5 秒的速度补回剩余时间，护眼最多 20 分钟，久坐和连续工作最多补到各自设定周期。例如护眼 17:32 离开 1 秒后变为 17:37。检测到新的鼠标、键盘或支持的外接设备操作后，从补回后的时间恢复正常倒计时，也可手动继续或再次按热键返回。触发离开的点击或快捷键释放不会马上解除离开模式。快捷键冲突时主窗口会提示，可用右键菜单操作。
- 休息开始时播放内置提示音，恢复并置顶休息窗口，尝试切换到前台。
- 休息结束会显示置顶的完成提示；继续工作、跳过或收起窗口后取消置顶。“休息”按钮可直接试用声音和窗口提醒。
- 托盘左键打开窗口，右键暂停、继续、立即休息或退出。
- 关闭或最小化窗口后继续运行；彻底退出请使用托盘菜单。
- 暂停保留工作倒计时；跳过休息后重新开始 20 分钟周期。
- 监听 Windows 锁屏和解锁：锁屏记录离开时间，三项均按 5:1 回补；解锁后保留回补结果，等待新的设备操作后继续。锁屏期间不响应输入、不弹提醒；休息完成后的等待状态不会被唤醒或解锁取消。锁屏与睡眠重叠只结算一次，手动暂停在解锁后仍保持暂停。
- 主窗口、设置和健康提醒统一深色配色、字体与按钮样式，主窗口将久坐与连续工作显示为剩余时间。
- 防止重复启动，资源管理器重启后重新添加托盘图标。
- 点击主窗口“设置”或托盘“提醒设置”可调整健康提醒和声音，设置保存至 `%LOCALAPPDATA%\EyeBreak202020\settings.ini`。
- 支持选择、试听自定义 WAV 音频，以及恢复默认音或关闭声音。建议使用短 PCM WAV，不支持 MP3；保存时复制到设置目录，文件失效时回退内置声音。
- 久坐提醒默认 60 分钟（可设 1–480）；连续工作过长默认 120 分钟（可设 1–720），各项可单独开关。
- 深夜提醒默认 23:00，截至次日 06:00，同一次运行中每晚只提醒一次。使用电脑本地时间，跨午夜不重复；若设为凌晨时间，则从该时间到当天 06:00。
- 护眼、久坐与连续工作共用一个单调时钟结算入口，只有工作状态消耗时间；护眼休息和等待继续时均停止累计，离开、锁屏和睡眠时按 5:1 回补。即使消息处理延迟，也不会把护眼已到期后的时间额外计入久坐。三项周期不同，因此剩余数值不必相同；重启软件重新计时。
- 护眼休息不会清零久坐或工作计时。每项达到阈值后仅提醒一次；确认活动、结束工作或回补到阈值以下后重新达到阈值时可再次提醒。同时到期的健康提醒合并显示。
- 提醒窗口或托盘中的“我已起身活动”只清零久坐；“结束本轮工作”清零两项并暂停，点击继续后开始新一轮。

## 构建

需要 Visual Studio 2022 的 C++ 桌面开发组件、Windows SDK 和 CMake。
在项目目录的 PowerShell 中执行：

```powershell
cmake -S . -B out -G "Visual Studio 17 2022" -A x64
cmake --build out --config Release
ctest --test-dir out -C Release --output-on-failure
.\out\Release\EyeBreak.exe
```

也可以在 Visual Studio 中选择“打开文件夹”，打开此项目。

## 初版范围

工作周期固定 20 分钟，不自动注册开机启动，不保存暂停状态或累计计时。
Windows 的通知设置可能隐藏托盘气泡；休息窗口仍会出现。
提示音内嵌在 EXE 中，不依赖系统通知音；静音或音频输出设备设置仍会影响声音。
Windows 有前台焦点保护，自动提醒不保证抢到键盘焦点；无法取得焦点时，窗口仍置顶并闪烁任务栏。独占全屏和锁屏等场景可能无法覆盖。
休息完成仅表示倒计时结束，软件无法判断用户是否实际远眺。
应用使用原创“眼睛＋时钟”图标，覆盖 EXE、托盘和窗口标题栏；桌面悬浮窗仅显示倒计时或状态文字。多显示器提醒和安装包可后续补充。

## 字体与图标

主窗口、设置和健康提醒共用紧凑字体层级：微软雅黑 UI 正文、按钮和输入框为 9 磅（96 DPI 下 12 像素），辅助说明为 11 DIP，主标题为 20 DIP，大倒计时为 56 DIP；全部随所在屏幕 DPI 缩放。主窗口客户区为 496×384 DIP，悬浮窗为 76×36 DIP，仅显示倒计时或状态文字。

设置中勾选“浅色模式（保存后应用）”并保存，即可切换浅灰背景、深色文字和绿色强调色；取消勾选并保存恢复深色模式。主题选择保存在本机设置文件，重启后保留。主窗口、原生设置/健康提醒、输入框、按钮和悬浮窗共用主题配色。

矢量图标源文件为 `assets/app-icon.svg`，预览为 `assets/app-icon.png`，Windows 图标为 `assets/app.ico`（16、20、24、32、40、48、64、128、256 像素）。小尺寸省去底部三点以提高托盘辨识度。安装 Pillow 后可运行 `python tools/build_icon.py` 重建，常规 C++ 构建无需 Python。

## 高 DPI 显示

程序使用 Per-Monitor V2 DPI 感知：主窗口的字体、间距和控件，以及悬浮图标的尺寸与圆角随所在显示器缩放，响应动态 DPI 变化。设置与健康提醒使用原生对话框自身的 DPI 字体，不再套用主窗口像素字体。设置窗口超过工作区高度时可滚动，Tab 聚焦的控件会自动滚入可见区域。

自动布局回归覆盖 100%、125%、150%、200% 的主窗口及悬浮图标尺寸，并验证设置字体和超高内容的滚动。真实混合 DPI 显示器之间的拖动仍需实机复测。

## 统一休息入口与每日统计

主窗口、托盘和悬浮窗单层菜单，以及深夜、久坐、连续工作提醒页均提供“立即休息”。手动立即休息进入回补状态：保留剩余时间，护眼、久坐、连续工作按 5:1 回补；可以从手动暂停进入，有新操作后恢复工作。界面不再单列“离开电脑”。自动到点的护眼休息仍使用可配置的时长（默认 25 秒），结束后等待新的输入或点击继续；休息前的旧输入和手柄回到中立状态不应重启计时。自动休息可“跳过休息”，也可点击立即休息转入回补。

右键菜单按状态显示暂停计时、跳过休息或继续工作；已在回补时隐藏立即休息；没有久坐累计时隐藏重置久坐；已清零并暂停时隐藏结束本轮工作。全部为单层菜单。

主界面显示今日使用时长，右键“每日使用统计…”可按日期查看历史。仅累计本软件运行期间的工作状态时间；暂停、自动休息、等待继续、休息回补、锁屏和睡眠均不计入。统计与提醒计时独立，5:1 回补、起身活动和结束本轮工作均不会扣减每日统计，也不记录输入内容。

统计保存至 `%LOCALAPPDATA%\EyeBreak202020\usage.tsv`，重启保留，从升级运行此版本后开始记录，无法追溯此前的使用时间。按电脑本地日期分日，午夜跨天分别累计；约每 30 秒及状态操作、锁屏、睡眠、正常退出时保存，异常终止可能丢失最后约 30 秒。统计文件采用临时文件写入后替换，读取损坏文件时保留原文件，不以空记录覆盖。时钟或时区被手动调整时，新增区间归入调整后的本地日期。

## 输入过滤与诊断日志

程序不以 GetLastInputInfo 的变化作为继续工作的依据，改用 Raw Input 键鼠/HID 和经过过滤的 XInput：忽略旧队列消息、松开事件、持续按键重复、小幅随机抖动和手柄回中。细小但连续的鼠标移动仍可恢复计时。解锁或自动唤醒本身不会开始工作，自动休息已完成的等待状态会保留。

诊断日志自动写入 `%LOCALAPPDATA%\EyeBreak202020\diagnostics.log`，记录本地时间、进程号、状态变化及触发类型（raw-mouse/raw-keyboard/raw-hid/xinput、命令、锁屏、电源事件）。不记录键值、输入文字或屏幕内容。约 2 MiB 轮换一次，保留当前和上一份 `.1` 文件。日志不上传服务器。
