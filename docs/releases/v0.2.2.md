# 20·20·20 v0.2.2（Android 原型修复）

Android：`EyeBreak-Android-v0.2.2.apk`，相同签名覆盖安装，或通过设置页“检查 GitHub 更新”。Windows 与同步参考服务未改动，附件沿用 v0.2.1。

- 修复通知倒计时到零后继续显示负数：每秒发布有零下限的剩余时间。
- 用下一次实际提醒的系统闹钟替代按分钟唤醒；到点接收器独立更新状态及通知，服务回收不再隐式暂停并取消提醒。
- 补齐休息开始和结束的应用内弹窗；授予悬浮窗权限后可在其他应用上方显示提醒，桌面悬浮倒计时可独立关闭。
- 迟到的护眼提醒从实际送达时开始完整休息，不再默默跳过休息；完成后等待新的操作或点击继续，日统计只计原工作截止时间之前的时间。
- 打开应用时启动后台提醒，提供通知、精确定时、弹窗、后台电池设置入口和“5 秒后测试提醒”。显式停止后台提醒的选择会保留。

请开启通知及精确定时权限，需后台弹窗时允许悬浮窗；部分系统还需单独允许后台弹出界面。无权限、勿扰、强制停止和厂商后台限制可能影响提醒，应用不会绕过系统设置。

Android 26 项单元测试通过，覆盖计时、迟到送达、休息等待、通知零下限、提醒截止时间及闹钟重排；lint 为 0 错误。实体设备上的权限、声音、弹窗和后台流程仍需验证。
