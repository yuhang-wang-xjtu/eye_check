# 20·20·20 v0.2.3（Android 通知与亮屏计时）

Android：`EyeBreak-Android-v0.2.3.apk`，相同签名覆盖安装，或在设置中检查 GitHub 更新。Windows 与同步参考服务未改动，附件沿用 v0.2.1。

- 本地模式以亮屏为使用判据：亮屏持续累计使用时间，每 20 分钟只发护眼通知，不进入强制休息或等待确认。
- 熄屏停止使用累计，三项提醒按 5:1 回补；再次亮屏自动计时，无需解锁、点击继续或回到应用。
- 去掉护眼、健康、深夜及测试提醒对话框、后台提醒弹窗和通知中的继续／停止等操作。
- 悬浮窗权限仅用于可选的悬浮倒计时，提醒本身只需通知及相应定时权限。
- 兼容旧版保存的自动休息和等待状态；迟到回调只补发一条护眼通知，下个截止时间保持在未来，不显示负数，不扣减历史。
- 手动暂停仍可主动使用，直到手动继续或再次熄屏、亮屏。共享模式以服务器周期为准，休息完成且亮屏在线时自动请求继续；手机熄屏不会暂停其他设备。

Android 33 项单元测试通过，lint 为 0 错误。真实设备上的系统通知、亮灭屏广播和厂商后台限制仍需验证。通知声音和横幅遵循系统设置。
