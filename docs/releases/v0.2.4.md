# 20·20·20 v0.2.4（Android 休息完成通知）

Android：`EyeBreak-Android-v0.2.4.apk`，相同签名覆盖安装，或在设置中检查 GitHub 更新。Windows 与同步参考服务未改动，附件沿用 v0.2.1。

- 每 20 分钟进入自动休息，默认 25 秒，可在设置中修改为 1–600 秒。
- 自动休息期间不累计每日使用时长、久坐和连续工作计时，亮屏也不例外。
- 休息开始、结束均发送系统通知，不弹出确认框，不要求选择继续或停止。
- 休息完成后亮屏自动开始下一轮；熄屏则保持 5:1 回补，直到再次亮屏。休息中熄屏不会取消结束通知，再亮屏不会提前跳过休息。
- 兼容已有休息截止时间；熄屏回补不重复结算，也不扣减每日历史记录。

Android 39 项单元测试通过，lint 为 0 错误，覆盖亮灭屏切换、休息完成通知、休息计时排除、自定义时长、迟到回调和跨日统计。系统通知、声音、真实设备后台和权限流程仍需实机验证。
