# 20·20·20 v0.2.1（原型）

## 下载与安装

- **Windows 10/11 x64**：下载 `EyeBreak-Windows-x64-v0.2.1.zip`，退出旧版后解压运行 `EyeBreak.exe`。设置和使用记录保留在用户数据目录。Windows 暂不提供应用内更新。
- **Android 8.0 及以上**：下载 `EyeBreak-Android-v0.2.1.apk` 覆盖安装，或在应用设置中检查 GitHub 更新。APK 为调试签名原型；相同签名的覆盖更新保留设置和记录。
- **同步服务**：`EyeBreak-Sync-Prototype-v0.2.1.zip` 提供参考实现、测试和部署说明，需要自行部署 HTTPS 服务。Windows 暂未接入同步接口。
- **校验**：`SHA256SUMS.txt` 提供附件的 SHA-256。

## 功能

20 分钟护眼提醒、可调休息时长、久坐和连续工作提醒、深夜提醒、声音设置、每日工作时间统计、5:1 休息回补和深浅色主题。休息完成后等待有效操作或手动继续。

Android 支持秒级通知倒计时、可选悬浮窗、共享会话同步原型和 GitHub 检查更新。更新下载后校验大小、SHA-256、包名、版本及签名，由用户确认系统安装。

移除环境专属文档和预置服务地址，构建产物不包含开发机器的绝对路径。Git 仓库以当前通用源码重新初始化。
